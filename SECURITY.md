# Security Policy

## Scope & Architecture
PromptCraft Pro is a local-first, zero-dependency prompt-engineering skill and verification standard. It does not call external model APIs, collect user telemetry, or require credentials.

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a prompt-injection vector, packaging flaw, or security issue in the build scripts, please report it via GitHub Private Vulnerability Reporting on this repository or email `abumoghli.6@gmail.com`.
