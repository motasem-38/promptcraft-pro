# PromptCraft Pro — التجربة والنشر العام

تاريخ التحقق: 6 نوفمبر 2026. الإصدار: 1.0.0.

## ما أُنجز

- تحويل المستودع إلى حزمة Agent Plugins 1.0 تحمل `plugin.json` في الجذر.
- الاحتفاظ بملف `skills/promptcraft-pro/SKILL.md` الأصلي دون تغيير حرف واحد.
- إضافة بيانات العرض، ثلاثة اقتراحات بدء، ثلاثة أمثلة مراجعة، وملاحظات إصدار.
- إضافة أيقونة مخصصة PNG بمقاس 512×512، وفحص وضوحها بمقاس 48×48.
- الناشر الذي اختاره المستخدم: Motasem Abumoghli؛ مجاني بلا مشتريات؛ جميع الدول التي تدعمها المنصة. تعني `countries: []` عدم إضافة قيود دول من الناشر، ولا تتجاوز قيود المنصة.
- التحقق من manifest بالمخطط الرسمي، وفحص محتويات ZIP والأيقونة وYAML والترخيص والقيود الخاصة بالرفع العام.
- تجهيز حزمة يمكن تثبيتها للتجربة قبل التقديم العام.

## التجربة قبل النشر

ابنِ ملف ZIP كما هو موضح أدناه، ثم ثبّته في بيئة تطوير تدعم Plugins، أو احفظ نسخة خاصة عبر Plugin Creator. اختر الإضافة في محادثة ثم نفّذ الحالات الموجودة في `SMOKE-TESTS.md`.

لا يثبت نجاح حفظ الحزمة نجاح تشغيل كل سلوك. لم تُسجّل نتائج اختبارات داخل ChatGPT في هذا المستودع. تأكد من الاسم المرتبط بهوية المطوّر عند الحفظ والتقديم، فقد يستبدل المضيف قيمة `developerName` بهوية الحساب.

## مراجعة البنية والتغليف

المستودع الأصلي Skill تعليمات، لا تطبيق API. لذلك تحافظ الحزمة على تصميم prompts وتكييفها وتقييمها دون خادم MCP أو استضافة أو OAuth أو مفاتيح API. لا تتصل بنماذج الطرف الثالث ولا تشغّل مقارنات أداء بينها. يمكنها صياغة prompts لهذه النماذج؛ تشغيلها هناك خطوة منفصلة.

الأرشيف العام يحتوي خمسة ملفات فقط: manifest، الترخيص، الأيقونة، Skill الأصلية، وملف عرض Skill الاختياري `agents/openai.yaml`. لا يحتوي `.app.json` أو ارتباطًا بالنسخة الخاصة أو `.git` أو أسرارًا أو اعتماديات تطوير. تُكتشف المهارات من `skills/` تلقائيًا؛ لا توجد حاجة إلى manifest قديم من نوع `ai-plugin.json`.

الأيقونة أُنشئت بأداة ImageGen المدمجة، ثم حُفظت في `assets/icon.png`. وصف التصميم: حرف P أبيض يجمع فقاعة محادثة، خلفية مرجانية من هوية الموقع، ولمسة teal صغيرة، بتفاصيل قليلة ووضوح في الأحجام الصغيرة.

## الروابط والسياسات

فُتحت الروابط التالية وأُعيدت استجابة 200 وفُحص محتواها بتاريخ التحقق:

- [الموقع](https://motasem-38.github.io/promptcraft-pro/): يعرّف المنتج، وظائفه، وترخيصه.
- [الدعم المستخدم في manifest](https://github.com/motasem-38/promptcraft-pro/issues): متتبّع المشكلات العام للمستودع، وهو مفعّل.
- [الخصوصية](https://motasem-38.github.io/promptcraft-pro/privacy.html): تصف ممارسات PromptCraft Pro نفسها، وتفصلها عن ممارسات المضيف والطرف الثالث.
- [الشروط](https://motasem-38.github.io/promptcraft-pro/terms.html): مجانية الاستخدام، مسؤولية مراجعة النتائج، وعدم ضمان المخرجات.

صفحة `support.html` المنشورة تتضمن نصًا مؤقتًا. أُصلحت النسخة المحلية لتحتوي رابط دعم مباشر، وكذلك فقرة التواصل في `terms.html`. تتضمن نسخة المصدر تعديل هاتين الصفحتين؛ يتطلب ظهورهما على الموقع اكتمال نشر GitHub Pages. يتجه manifest بالفعل إلى متتبّع المشكلات العامل، فلا يعتمد على نشر تعديل صفحة الدعم. لم نغيّر التزامات الخصوصية أو الشروط القانونية المنشورة؛ على الناشر تأكيد ملاءمتها وممارساته عند التقديم.

تنبيه دقة المتطلبات: وثائق OpenAI الحالية تجعل الروابط الأربعة إلزامية لمراجعة MCP، ولا يشترطها التحقق من بيانات skills-only جميعها. أدرجناها مع ذلك، وكلها وجهات فعلية. راجع متطلبات البوابة عند الرفع؛ يمكن أن تتغير.

## خطوات التقديم العام

1. أكمل تجربة الحالات في `SMOKE-TESTS.md` على النسخة المثبتة وسجّل النتائج، وأصلح أي سلوك غير مناسب قبل التقديم.
2. اختر المؤسسة والمشروع المالكين للإضافة في [بوابة Plugins](https://platform.openai.com/plugins). أكمل تحقق الهوية الفردية أو التجارية باسم Motasem Abumoghli. يلزم أن تكون مالك المؤسسة أو تمتلك صلاحية **Apps Management Write**.
3. اختر **Upload new or existing plugin** وارفع `promptcraft-pro-1.0.0.zip`، ثم اختر هوية المطوّر الموثقة. هذه الخطوة تنشئ مسودة للتقديم، ولا تنشر الإضافة.
4. افحص النسخة المحفوظة: Skill واحدة، الاسم، اسم الناشر، الأيقونة، التصنيف Productivity، المجانية، البلدان، الروابط، وملاحظات الإصدار. تحقق من ظهور جميع الدول كما قصدت؛ اسم الناشر العام يعتمد على الهوية الموثقة وليس نص manifest وحده.
5. انتظر اكتمال فحوص **Metadata & Skills** بنجاح. أصلح الملاحظات في المصدر وأعد بناء ZIP عند الحاجة. لا يُعد الفحص المحلي بديلًا عن فحص OpenAI.
6. لهذه النسخة skills-only لا يلزم خادم أو ربط MCP أو فيديو مراجعة أو بيانات دخول مراجع أو مجموعة حالات MCP ذات 5 إيجابية و3 سلبية. أمثلة الاستخدام موجودة في `review.prompts` وليست اختبارات MCP.
7. المطوّر المخوّل هو من يكمل إقرارات السياسات والقانون الظاهرة في البوابة، ومنها الإقرارات المتعلقة بعدم استهداف الأطفال دون 13 عامًا أو مشاركة بياناتهم الشخصية مع OpenAI. لم نقبل أو نؤكد هذه الإقرارات بالنيابة عنك.
8. بعد استيفاء المتطلبات اختر **Submit for review**. بعد الموافقة، يبقى **Publish** إجراءً منفصلًا؛ تحقق من الإصدار والجمهور والدول ثم انشره.

التحقق من النطاق يُستكمل إذا طلبته البوابة؛ لا يوجد نطاق خادم MCP في هذه الحزمة. لا يمكن لحزمة ZIP ضمان القبول أو توثيق الهوية أو الموافقة القانونية. لم تُرفع مسودة عامة، ولم تُرسل للمراجعة، ولم تُنشر في الدليل.

قيد مهم للتوسع: وفق الوثائق الحالية، لا يُدعم إضافة خادم MCP إلى Plugin بدأ skills-only لاحقًا. إذا أردت مستقبلًا تشغيل نماذج أو benchmark عبر API، خطّط لذلك كمنتج/إضافة جديدة وفق دعم المنصة؛ الوظائف الأصلية لا تحتاجه.

## إعادة البناء وتحديث المستودع

يتضمن المستودع صفحات الدعم وmanifest والأيقونة والأدلة وأدوات البناء. يُنشأ الأرشيف خارج مجلد المصدر، وتُستبعد منه صفحات الموقع وأدوات التطوير.

من المجلد الأب لـ `promptcraft-pro`:

```bash
python promptcraft-pro/scripts/build_plugin.py promptcraft-pro-1.0.0.zip
python promptcraft-pro/scripts/validate_plugin.py promptcraft-pro-1.0.0.zip
```

أداة البناء تستخدم مكتبة Python القياسية فقط. أداة التحقق تحتاج Pillow وPyYAML وjsonschema، واتصالًا لجلب مخطط manifest الرسمي. أعد بناء الأرشيف وفحصه بعد أي تغيير. لا تعدّل ملف الأرشيف يدويًا.
