Common questions

How do I get better results?

State the goal, provide relevant context, define constraints, and specify the desired output format. PromptCraft Pro can help turn those ingredients into a more testable prompt.

How do I install PromptCraft Pro?

Install it from the public GitHub repository with npx skills@latest add https://github.com/motasem-38/promptcraft-pro --skill promptcraft-pro. The repository README includes options for Claude Code, Codex, GitHub Copilot, Gemini CLI, and other compatible agents.

Which models are supported?

PromptCraft Pro provides model-aware guidance for OpenAI GPT, Anthropic Claude, Google Gemini, xAI Grok, and other language models. Capabilities can vary by model and platform.

How do I report a problem?

For now, please use the support channel provided with the plugin listing or the repository’s issue tracker. A public contact address has not been supplied for this draft, so no address is invented here.

Reference sources

Model documentation referenced by PromptCraft Pro is available from OpenAI, Anthropic, Google Gemini, and xAI. These are independent third-party sources.

Important: PromptCraft Pro is a prompt-engineering assistant. It does not guarantee a particular model response, outcome, availability, or third-party platform behavior.
